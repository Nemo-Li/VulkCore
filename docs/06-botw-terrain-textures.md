# 地形材质与分距离渲染

## 当前 `.mate` 渲染路径

地形从 `terrain/<分组>.mate/<瓦片>.mate` 读取材质，也支持放在 `terrain/` 下的单个 `.mate`。每个文件是 256 × 256 的四字节网格，前两字节为材质 ID，第三字节按第一材质的归一化权重解释，第四字节随样本保留。近处采样使用相邻同尺寸瓦片的一圈纹素补边。GPU 先按权重混合每个样本的两张底色，再对相邻样本的颜色做双线性插值。纹素中心的采样坐标让两侧在共享边读取同一组样本。

地表底色从 `source/Terrain.Tex.sbfres` 的 `MaterialAlb` 数组解码，并保留底色的色彩空间。`.mate` 材质 ID 用作 BNTX 用户数据 `array_index` 的行号，表值是实际的纹理层号。`source/material-albedo-layers.txt` 可显式覆盖或补充映射，每行填写十进制材质 ID 和从零开始的数组层号，支持 `#` 注释。若启用的材质 ID 缺少映射，瓦片会被跳过。没有档案的材质包可在 `materials/` 下按材质 ID 提供同尺寸的原创底色 PNG。仓库所附资源的完整映射见[地形材质 ID 与纹理层对照表](11-botw-terrain-material-mapping.md)。

贴图沿世界 XZ 每 4 个单位重复一次，并在线性空间混合。缺少有效 `.mate` 的瓦片从绘制和阴影投射中剔除。使用 PNG 时，有效材质 ID 对应纹理缺失也会跳过瓦片。高度查询和碰撞仍使用 `.hght`。启动日志列出可绘制瓦片数和缺失的 PNG 材质 ID。

场景加载时，先在线性空间计算每层底色的平均色，再用带补边的材质权重烘焙一张覆盖整个地形的远景底色图。地图使用统一的 XZ 坐标，目标采样间距为 4 个世界单位，最长边上限为 2048 纹素。图像以线性格式生成 mip，用 Alpha 记录覆盖率，避免缺瓦片处的空白污染粗 mip。着色器在 95–340 个世界单位之间平滑混合近景与远景。单像素覆盖范围较大时可以提前进入远景路径，完成底色过渡后停止采样近景贴图。

加载器通过 BNTX `file` 元数据识别名称以 `Rock_` 开头的岩石层，沿用 `.mate` 权重与跨瓦片滤波生成带 mip 的岩石覆盖图。近处按覆盖率混合三平面底色和程序化颗粒法线。中距离使用世界空间层理、碎裂和凹槽暗化，按屏幕像素覆盖范围逐步淡出。岩石法线扰动用于地表漫反射，阴影采样使用网格法线。缺少岩石分类的材质包沿用常规底色采样。

近景补边支持同尺寸瓦片。

## 旧地形材质路径

以下为旧方案和资源格式的调研记录。旧式图集和宏观控制图已经从当前渲染路径移除。

参考截图中的浅绿草甸、暖赭色裸土、层状岩壁及冷蓝远山用于校准色调与细节尺度。岩土等地形使用程序生成的材质。草地地表使用 `assets/terrain/source/` 中 `MaterialAlb` 和 `MaterialCmb` 的第 0 层，植被使用同一资源包中的草叶、覆盖图和草片。

## 纹理生成与分区

- `terrain_<type>.png` 是 512×512 的 sRGB 底色。生成器叠加多尺度周期噪声，并对噪声坐标做域扭曲。各材质再加入不同尺度的叶片、砂纹、裂纹或碎石。所有材质在纹理边界周期衔接。
- `terrain_<type>_surface.png` 是 512×512 的线性 RGBA。RGB 存储根据同一高频地表生成的切线空间法线，A 存储八方向估算的环境光可见度。V 沿图片行号增长。
- `terrain_macro.png` 是覆盖整个载入地形的 1024×1024 线性 RGBA 控制图。R 控制湿润与植被倾向，G 控制含铁岩层与暖色倾向，B 控制沉积与裸土，A 控制大尺度明暗。所有瓦片共用地形 X/Z 边界归一化的 UV。坡度、高程和扭曲后的地形空间噪声共同决定草、土、岩的边界。大尺度地貌权重独立于距离，避免相机移动时草坡逐渐变成裸岩。
- 两个 Vulkan 纹理数组按草、土、岩、沙、雪、泥、砾石、火山灰的顺序装载，每层独立生成 Mip。旧资源包可回退到 4×2 的 `terrain_atlas.png`，并将采样限制在相应图格内。缺少整图或表面图时，分别使用连续程序噪声或几何法线。TSCB 的 U/V 缩放继续控制近景纹理的采样密度。

## Switch 地形材质样本

这次分析的 `Terrain.sbfres` 与 `Terrain.Tex.sbfres` 都是 Yaz0 压缩的 Switch BFRES 5.0.3 文件。前者包含 7 个模型和 34 个形状。后者内嵌 `textures.bntx`，包含 22 个带压缩像素数据的纹理条目。

`Tera` 是地形子系统使用的内部前缀，很可能取自 `Terrain`。模型名包括 `TeraTerrain`、`TeraRoute`、`TeraGrass`、`TeraFlower`、`TeraTree`、`TeraWater` 和 `Horizon`。公开反编译代码在 `KingSystem/Terrain` 下使用了 `ksys::tera` 命名空间。 [teraSystem.h](https://github.com/zeldaret/botw/blob/master/src/KingSystem/Terrain/teraSystem.h)

### 地表底色与组合图

| 纹理 | 规格 | 材质用途 |
| --- | --- | --- |
| `MaterialAlb` | 83 层，每层 1024×1024，11 级 mip，BC1 sRGB（`0x1A06`） | 地形和道路的底色，绑定到 `_a0` |
| `MaterialCmb` | 83 层，每层 512×512，10 级 mip，BC1 UNORM（`0x1A01`） | 地形和道路的线性组合图，供 `_n0` 法线槽与 `_s0` 高光槽采样 |

83 是二维纹理数组的层数。采样坐标的第三分量选取 `0–82` 中的一个图层，每层各有自己的 mip 链，采样时另行选择 mip 级别。

`Cmb` 很可能是 `Combined` 的缩写。地形不透明材质的 ShaderAssign 将 `_n0` 和 `_s0` 指向同一个材质槽，道路材质将两个槽都填为 `MaterialCmb`。抽查 15 层解码数据时，R、G 的中位数集中在 128 附近，结合绑定推测这两个通道存放法线的 X、Y 分量。B 存放分布随材质变化的灰度数据，可能用作高光遮罩。BNTX 的组件选择是 `R/G/B/B`，因此 GPU 采样结果的 A 和 B 读取同一个分量。法线重建公式、B 通道的高光计算与强度仍需原着色器验证。

### 其他纹理

| 用途 | 条目 |
| --- | --- |
| 水面和地平线 | `WaterAlb`、`WaterNrm`、`WaterEmm`。水材质分别绑定底色、法线和自发光相关槽位，`Horizon` 引用后两项。 |
| 草 | `GrassAlb`、`GrassCoverAlb`、`GrassCrossAlb`、`GrassSpm`。本项目将前三项分别用于近景底色、草根覆盖和中景卡片，以 `GrassSpm` 调制植被高光。 |
| 花与地表小物件 | `FlowerCrossAlb`、`FlowerFallenLeavesAlb`、`FlowerLongAlb`、`FlowerNormalAlb`、`FlowerPetalAlb`、`FlowerStoneAlb`、`FlowerShellAlb`、`FlowerChipsAlb`。 |
| 树 | `Tree0Alb`、`Tree0NrmTrs`、`Tree1Alb`、`Tree1NrmTrs`、`TreeDitherMask`。两对树贴图分别有 100 层和 49 层，另有一张抖动遮罩。 |

### 形状绑定与地图材质分布

形状通过 `FSHP.materialIndex` 选择 `FMAT`，材质按槽位记录采样器和贴图名，再从 BNTX 的同名记录取图。样本中的 `TeraTerrain / NormalNear` 选用 `OpaqueNear`，由 `_a0` 读取 `MaterialAlb`，由 `_n0` 读取 `MaterialCmb`。 [SBFRES 材质解析](09-sbfres-import.md)

`TeraTerrain` 的 7 个形状各含 3 个顶点，只有位置属性。近、中、远形状共用三角形坐标，分别对应 `OpaqueNear`、`OpaqueMiddle` 和 `OpaqueFar`。实际地图网格依赖瓦片布局和 `.hght` 高度数据，地表材质分布依赖 `.mate`。现有 `MainField.tscb` 有 88 条材质记录，两个纹理数组各有 83 层，并包含相同的 `array_index` 映射。 [地形文件结构](https://zeldamods.org/wiki/Terrain) · [VulkCore 地图加载](../src/Terrain/Terrain.cpp)

### 本地导出与 VulkCore 支持

`MaterialAlb` 的本地导出位于 `exports/MaterialAlb/`。`MaterialAlb_00.png` 至 `MaterialAlb_82.png` 保留数组层号，每张是从 mip 0 解码出的 1024×1024 RGBA8 sRGB 图。解码过程先展开 Yaz0，再按 BNTX 数组层跨度定位各层，对 BC1 块解除 Tegra 平铺并解码。83 张图已逐张回读核对。本地解析清单位于 `build/terrain-sbfres-analysis/`。

VulkCore 的地形着色器已有 `sampler2DArray` 绑定，当前从项目生成的 PNG 组装底色与表面数据。样本中的 `MaterialCmb` 与项目的 `*_surface.png` 使用各自的通道约定，项目的表面图存放 RGB 法线和 A 环境光可见度。通用模型材质导入使用单层二维贴图。`sbfres_viewer` 可以独立浏览 BNTX 内各纹理的数组层，模型页用默认贴图显示引用数组的几何。 [当前地形着色器](../shaders/src/shader_terrain.frag) · [查看器用法](09-sbfres-import.md#查看地形模型和纹理包)

## 距离和像素覆盖范围

| 范围（地形世界单位） | 采样方式 |
| --- | --- |
| 近景，到约 150 | 三平面投影覆盖陡坡和平台。八种材质采用三角网格随机采样，每个节点固定随机偏移、旋转和缩放。相邻三角形共享边上的采样点，权重连续地混合。法线和 AO 共用底色的投影，其中法线梯度转换回原投影空间。法线和 AO 在 28 至 110 单位间淡出，岩石的细节层延长至 280 单位。 |
| 中景，150 至 520 | 根据距离平滑混合岩土细节与低频颜色。草地继续采样 `MaterialAlb`，由 mip 滤波保留低频色彩。显式纹理梯度保留正确的 Mip，较大的像素覆盖范围会进一步削弱细节，尤其是以小角度掠过地面的视线。 |
| 远景，520 之后 | 按权重混合底色和宏观控制。低频岩板三平面采样保留断续的岩块与遮蔽。两个不同尺度的海拔色带沿山体延伸，色差和法线按像素足迹衰减，减弱高频闪烁。距离雾及山谷浮雾降低远景对比度，背光岩面叠加冷色天空光。 |

按投影轴复用随机变换，裁掉低权重的材质、投影轴和三角网格样本。远景的岩石使用较低频的纹理采样，其他材质使用底色和程序变化。细节数组和全图控制图使用 Vulkan RGBA8 时，包含完整 Mip 的常驻图像约为 26.7 MiB。使用全图控制图的纹理数组路径复用材质底色描述符。

## 高度场平滑与法线

生成网格前，加载器先修复孤立的高度尖峰，并统一相邻瓦片的共享边和角点，再对同分辨率瓦片执行八轮可分离的 `[1, 2, 1] / 4` 滤波。滤波的标准差为两个原始采样间距，在项目瓦片中约为 4.9 米。这会平滑步长为二的采样容易放大的狭窄高度突变，保留大尺度地貌与平面坡面。缺少邻瓦片时使用边缘采样值。高度查询、草簇放置、网格包围盒、渲染与 PhysX 碰撞网格都使用内存中的滤波结果，原始 `.hght` 文件保留。

地形法线取自完整的滤波高度场。拼接网格时，共享顶点混合这些法线，使基于坡度的材质混合和光照沿瓦片边界连续。`vulkcore_terrain_smoke` 覆盖陡坡平滑、孤立尖峰、共享边与角点（含缺瓦片）、坡面与平台保留，以及网格、高度查询和高度场法线的一致性。

## 重新生成

安装 NumPy 和 Pillow 后，在仓库根目录运行：

```bash
python3 scripts/generate_terrain_materials.py
```

脚本使用固定随机种子。用 `--output /path/to/textures` 生成到单独的目录。更新土壤和岩石时，将 `terrain_dirt.png`、`terrain_rock.png`、对应的 `_surface.png` 和同步生成的图集复制回项目。场景的草地底色与表面纹理从地形档案加载。更改底色配方后，同步更新 `shader_terrain.frag` 的 `kLandformAverages`，保持远近颜色的过渡。`vulkcore_terrain_smoke` 检查整图 UV 跨瓦片的连续性。

```bash
./build/vulkcore --scene scenes/game.scene --hide-ui
```
