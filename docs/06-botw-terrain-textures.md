# 地形材质与分距离渲染

参考截图中的浅绿草甸、暖赭色裸土、层状岩壁及冷蓝远山用于校准色调与细节尺度。地形材质数组使用程序生成的色块与细节。`scenes/game.scene` 的近景地表草由 `grass_settings` 指定，草叶与地表共用采样和光照。

## 参考图分析与改进方向

下表的参考图手法来自单帧画面的视觉推断。确认原游戏的着色算法、光照参数和贴图分层需要引擎资料。

| 地物 | 参考图可见的特征 | VulkCore 实现 | 仍有差距与改进方向 |
| --- | --- | --- | --- |
| 远山 | 红褐色岩壁有横向层理。背光坡偏冷，远处山体的对比度更低。 | 用两种尺度的海拔色带表现层理，辅以低频三平面采样和法线扰动。场景采用偏暖的直射光、偏冷的环境光、距离雾和山谷浮雾。 | 当前山体主要靠高度场和着色表现层理，缺少清楚的实体崖沿和外凸岩台。可给现有山体补原创崖面和断层网格，并把灰色基岩与红色沉积岩拆为独立材质。 |

## 纹理生成与分区

- `terrain_<type>.png` 是 512×512 的 sRGB 底色。生成器叠加多尺度周期噪声，并对噪声坐标做域扭曲。各材质再加入不同尺度的叶片、砂纹、裂纹或碎石。所有材质在纹理边界周期衔接。
- `terrain_<type>_surface.png` 是 512×512 的线性 RGBA。RGB 存储根据同一高频地表生成的切线空间法线，A 存储八方向估算的环境光可见度。V 沿图片行号增长。
- `terrain_macro.png` 是覆盖整个载入地形的 1024×1024 线性 RGBA 控制图。R 控制湿润与植被倾向，G 控制含铁岩层与暖色倾向，B 控制沉积与裸土，A 控制大尺度明暗。所有瓦片共用地形 X/Z 边界归一化的 UV。坡度、高程和扭曲后的地形空间噪声共同决定草、土、岩的边界。大尺度地貌权重独立于距离，避免相机移动时草坡逐渐变成裸岩。
- 两个 Vulkan 纹理数组按草、土、岩、沙、雪、泥、砾石、火山灰的顺序装载，每层独立生成 Mip。旧资源包可回退到 4×2 的 `terrain_atlas.png`，并将采样限制在相应图格内。缺少整图或表面图时，分别使用连续程序噪声或几何法线。TSCB 的 U/V 缩放继续控制近景纹理的采样密度。

## 距离和像素覆盖范围

| 范围（地形世界单位） | 采样方式 |
| --- | --- |
| 近景，到约 150 | 三平面投影覆盖陡坡和平台。八种材质采用三角网格随机采样，每个节点固定随机偏移、旋转和缩放。相邻三角形共享边上的采样点，权重连续地混合。法线和 AO 共用底色的投影，其中法线梯度转换回原投影空间。法线和 AO 在 28 至 110 单位间淡出，岩石的细节层延长至 280 单位。 |
| 中景，150 至 520 | 根据距离平滑混合细节与低频颜色。地表草地与近处草叶共用绿色底色，从约 45 单位起逐步褪绿，保留底色纹理的明暗。显式纹理梯度保留正确的 Mip，较大的像素覆盖范围会进一步削弱细节，尤其是以小角度掠过地面的视线。 |
| 远景，520 之后 | 按权重混合底色和宏观控制。低频岩板三平面采样保留断续的岩块与遮蔽。两个不同尺度的海拔色带沿山体延伸，色差和法线按像素足迹衰减，减弱高频闪烁。距离雾及山谷浮雾降低远景对比度，背光岩面叠加冷色天空光。 |

按投影轴复用随机变换，裁掉低权重的材质、投影轴和三角网格样本。远景的岩石使用较低频的纹理采样，其他材质使用底色和程序变化。细节数组和全图控制图使用 Vulkan RGBA8 时，包含完整 Mip 的常驻图像约为 26.7 MiB。使用全图控制图的纹理数组路径复用材质底色描述符。

## 高度场平滑与法线

生成网格前，加载器先修复孤立的高度尖峰，并统一相邻瓦片的共享边和角点，再对同分辨率瓦片执行八轮可分离的 `[1, 2, 1] / 4` 滤波。滤波的标准差为两个原始采样间距，在项目瓦片中约为 4.9 米。这会平滑步长为二的采样容易放大的狭窄高度突变，保留大尺度地貌与平面坡面。缺少邻瓦片时使用边缘采样值。高度查询、草簇放置、网格包围盒、渲染与 PhysX 碰撞网格都使用内存中的滤波结果，原始 `.hght` 文件保留。

地形法线取自完整的滤波高度场。拼接网格时，共享顶点混合这些法线，使基于坡度的材质混合和光照沿瓦片边界连续。`vulkcore_terrain_smoke` 覆盖陡坡平滑、孤立尖峰、共享边与角点（含缺瓦片）、坡面与平台保留，以及网格、高度查询和高度场法线的一致性。

## 重新生成

安装 NumPy 和 Pillow 后，在仓库根目录运行：

```bash
python3 scripts/generate_terrain_materials.py
```

脚本使用固定随机种子。用 `--output /path/to/textures` 生成到单独的目录。更新土壤和岩石时，将 `terrain_dirt.png`、`terrain_rock.png`、对应的 `_surface.png` 和同步生成的图集复制回项目。场景当前单独使用 `terrain_grass.png` 作为近景地表草纹理，更新岩土时可保留该文件。更改底色配方后，同步更新 `shader_terrain.frag` 的 `kLandformAverages`，保持远近颜色的过渡。`vulkcore_terrain_smoke` 检查整图 UV 跨瓦片的连续性。

```bash
./build/vulkcore --scene scenes/game.scene --hide-ui
```
